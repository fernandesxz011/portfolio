01DESENVOLVIMENTO WEB

TRS Serralheria

Uma apresentação digital para explorar serviços, hierarquia visual e navegação em uma landing page conceitual.

  • HTML
  • CSS
  • JavaScript
Por dentro do projeto +

Desafio

Explorar como organizar serviços de serralheria em uma página de leitura direta e navegação simples.

Solução desenvolvida

Seções de serviços, apresentação e contato, layout responsivo e animações com IntersectionObserver que respeitam movimento reduzido.

Aprendizados e prática

Hierarquia visual, organização por âncoras e equilíbrio entre movimento e acessibilidade.

Estágio atual

Protótipo frontend. Canal de contato pendente e conteúdo comercial a confirmar; não representa uma entrega oficial para a empresa.

02INTERFACE & INTERAÇÃO

Luia Veículos

Um protótipo de vitrine automotiva que conecta a busca por um veículo à preparação de uma conversa comercial.

  • HTML
  • CSS
  • JavaScript
Por dentro do projeto +

Desafio

Organizar a descoberta de veículos com critérios de busca e um caminho claro para demonstrar interesse.

Solução desenvolvida

Busca com normalização de acentos, filtros combinados, estado sem resultados, favoritos temporários e preparação de mensagens para WhatsApp.

Aprendizados e prática

Manipulação do DOM, estados da interface, combinação de filtros e distinção entre uma simulação local e uma integração real.

Estágio atual

Demonstração frontend em desenvolvimento. Imagens e dados comerciais pendentes; simulador e validação ainda precisam de ajustes documentados no repositório. Sem integração bancária.

03ANÁLISE DE DADOS

Além das planilhas.

Um estudo de vendas em Excel para transformar registros em tabelas, indicadores e visualizações por produto.

  • Microsoft Excel
  • Fórmulas
  • Tabelas dinâmicas
Por dentro do projeto +

Desafio

Praticar a organização de uma base de vendas e a leitura de valores agregados por categoria e produto.

Solução desenvolvida

Tabelas estruturadas, fórmulas de soma e condições, indicadores, tabela dinâmica e gráfico de colunas.

Aprendizados e prática

Organização de dados, referências de fórmulas e interpretação dos limites de cada indicador. Os valores são da base de estudo, não resultados comerciais.

Sobre a captura

Imagem original disponível no repositório, com dados agregados por produto. As abas com dados pessoais não são reproduzidas aqui.
